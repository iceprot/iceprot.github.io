# iceprot.github.io

Site de lancement ICEPROT — glace à l'eau protéinée. Page statique servie par GitHub Pages, sans étape de build.

- `index.html` : la page (styles et logo vectoriel intégrés).
- `mentions-legales.html` : mentions légales (champs entre crochets à compléter).
- `assets/` : logo blanc / noir avec baseline COLD NUTRITION, wordmark seul, favicon (avatar orange / beige).

Le wordmark est Poppins ExtraBold vectorisé (approche −0,025 em). Le filet en réserve va du fût du I au fût du T, centré sur la barre centrale du E, épaisseur 7,5 % de la hauteur des capitales.
